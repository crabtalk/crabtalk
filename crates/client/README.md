# crabtalk-client

Client library for the [Crabtalk](https://github.com/crabtalk/crabtalk) daemon.

Connection setup over UDS or TCP, typed RPC sugars, stream accumulation, and bot
command parsing — what an app needs to talk to `crabtalkd`.

## Users

- [`crabtalk-cli`](https://crates.io/crates/crabtalk-cli) — terminal client
- [`crabtalk-telegram`](https://crates.io/crates/crabtalk-telegram) — Telegram gateway
